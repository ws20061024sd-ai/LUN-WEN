# 论文排版与 PDF 导出指南

> 目标：将正文.md 导出为学术期刊风格的 PDF（宋体正文、黑体标题、两端对齐、页码）。最终方案：HTML → 浏览器打印 PDF。

---

## 一、最终方案（已实现）

### 生成 HTML

```bash
cd "/Users/xoln/Desktop/编程/论文"
python3 convert_to_pdf.py
```

自动生成 `正文.html` 并在浏览器打开。

### 导出 PDF

1. 浏览器中 Cmd+P 打开打印对话框
2. 展开「更多设置」
3. **取消勾选「页眉和页脚」**（页码由 CSS `@bottom-center` 自动生成，不需要浏览器自带）
4. 另存为 PDF

---

## 二、排版规格

| 项目 | 设置 |
|------|------|
| 纸张 | A4（210mm × 297mm） |
| 页边距 | 上下 2.54cm，左右 3.18cm，底部 3.0cm |
| 主标题 | 黑体 20pt，粗体，居中（唯一居中元素） |
| 正文标题 | 黑体 14pt，粗体，左对齐 |
| 正文 | 宋体 12pt，1.75 倍行距，段首缩进 2em，两端对齐 |
| 摘要 | 楷体 11pt，左右缩进 1.2em，内联"摘要："标签 |
| 关键词 | 11pt，左右缩进 1.2em |
| 注释 | 宋体 8.5pt，1.55 倍行距，左对齐 |
| 注释前分隔线 | 0.5pt 细线 |
| 页码 | 页面底部居中，Times New Roman 9pt |

---

## 三、生成文件

| 文件 | 用途 |
|------|------|
| `正文.md` | Markdown 源文件（可直接编辑） |
| `正文.html` | 排版后的网页（浏览器打开 → 打印 PDF） |
| `convert_to_pdf.py` | 转换脚本（修改正文.md 后重新运行即可） |
| `正文.docx` | Word 备用版（python-docx 生成，排版略逊于 HTML） |

---

## 四、已尝试但放弃的方案

| 方案 | 结果 |
|------|------|
| Markdown → Pandoc → Word → PDF | Pandoc 未安装 |
| Markdown → WeasyPrint → PDF | 缺系统库（Pango/GObject） |
| Markdown → python-docx → Word → PDF | 已生成 docx，但排版精细度不如 HTML+CSS |

---

## 五、再次生成

如果修改了正文.md，运行：

```bash
cd "/Users/xoln/Desktop/编程/论文"
python3 convert_to_pdf.py
```

HTML 会自动刷新，浏览器中重新 Cmd+P 即可导出新 PDF。
